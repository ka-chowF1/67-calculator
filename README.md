# 67 Calculator

A joke calculator: equations that equal 67 display Error. Every other result displays 67.

## Development

Run `npm start` to preview at http://localhost:8067. Run `npm test` and `npm run check` to validate. No package installation is required.

## Deployment

GitHub Actions publishes the dist folder to GitHub Pages after tests pass on main. In Settings > Pages, select GitHub Actions as the source.
